# Decaprio Fashion International — Official Website

Official website and landing page for **Decaprio Fashion International**, premier cut & sew custom clothing and sportswear manufacturer based in Sialkot, Pakistan.

## 🚀 Built With
- **React 18**
- **Vite 6**
- **Modern Responsive CSS** with interactive animations and smooth scrolling
- **Full SEO & Structured Data** (Google FAQ Schema, LocalBusiness Schema, 60+ targeted keywords, OpenGraph, sitemap.xml & robots.txt)
- **Local High-Resolution Assets** (All original product and factory photography included)

## 🛠️ Local Development
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

## 🌐 Deploy to Vercel
1. Import repository in [Vercel](https://vercel.com).
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**!
